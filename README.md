# React App (Vite)

Skeleton React project created with Vite (JavaScript).

Quick start (PowerShell on Windows):

1. Open PowerShell at `G:\UNIVERSIDAD\NASA\react-app`
2. Install dependencies:

```powershell
npm install
```

3. Start the development server:

```powershell
npm run dev
```

4. Open the URL shown by Vite (default http://localhost:5173).
